The waste stream is a commodity market nobody is pricing.

Reclaim is Baryon's material arbitrage engine. Point it at any listing for scrap, surplus, or unwanted equipment — an auction lot, a marketplace find, a pile behind a shop — and it estimates what the material is actually worth, what it costs to recover, and whether the trade is worth making.

DISCOVER → IDENTIFY → VALUE → OPTIMIZE → ACQUIRE → ROUTE → VERIFY → LEARN
How it works

Every object is a bundle of commodities with a logistics problem attached.

Reclaim reads a listing and decomposes it: objects → materials → weights → recoverable fractions. It prices each fraction against sourced scrap benchmarks, compares scrap value against reselling intact or parting out — the value waterfall — then subtracts the full cost of recovery: loading, transport, processing, disposal, and a risk reserve. What's left is the number that matters: expected net.

EXAMPLE — "FREE: old commercial electrical equipment, must haul away"
Estimated weight~2,400 lb
Copper (wire, windings, bus)~310 lb
Steel / mixed ferrous~1,450 lb
Estimated gross recovery$1,720
Pickup, transport, processing−$635
Risk reserve−$150
Expected net$935

Illustrative figures. Real appraisals carry weight ranges, per-material pricing with sources and as-of dates, and a stated confidence.

The engine

Built on the same world model as Resource Intelligence.

Sourced pricing

Scrap benchmarks with a source and an as-of date on every row, refreshed by an autonomous research agent — the same honest-data discipline as Baryon's world model.

Value waterfall

Resell intact, part out, or scrap — the engine recommends the highest-value realistic disposition, not just the commodity number.

Provenance first

Theft-prone material — copper, catalytic converters, utility equipment — is flagged automatically. Clean ownership is a requirement, not an afterthought.
